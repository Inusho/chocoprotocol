Dieser Ordner enthält die Laufzeit-Daten des Bots.
Beim ersten Start werden die Dateien automatisch erstellt.

- settings.json → Alle Einstellungen (Twitch, Discord, Moderation)
- custom-commands.json → Eigene Chat-Commands
- notifications.json → Benachrichtigungs-Texte
- discord.json → Discord-Event-Nachrichten
- disabled-commands.json → Deaktivierte Built-In Commands
