ℹ️ So richtest du es ein:

  1. Logge dich auf dev.twitch.tv mit deinem Bot-Account ein
  2. Erstelle eine Anwendung (Redirect URL: http://localhost, Kategorie: Chat Bot)
  3. Kopiere die Client-ID und optional das Client Secret
  4. Mache deinen Bot zum Moderator in deinem Kanal: /mod BotName
  5. Generiere ein neues OAuth-Token mit dem Scope moderator:read:followers
